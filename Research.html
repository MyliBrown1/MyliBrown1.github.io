Anomaly Identification and Detection Using Statistical and Machine Learning Methods

This study investigates methods for identifying anomalies in retail demand forecasting data using both statistical techniques and machine learning models, with the goal of reducing forecast error in perishable food inventory planning. Working with a large-scale retail company's dataset, the project builds an end-to-end anomaly detection pipeline — data cleaning, statistical analysis, and model development on a cloud-based data platform.

Anomalies are defined as forecast errors exceeding ±3 standard deviations from the mean. Data is segmented by item–store combination, with feature engineering applied to improve separability between normal and anomalous observations. An Isolation Forest model is then trained and tuned to prioritize catching the minority (anomalous) class in a highly imbalanced dataset.

The results show the value of combining statistical rules with machine learning into a scalable framework for identifying errors in perishable-item demand forecasting within a large retail environment.
